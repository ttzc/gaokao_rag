# 输出整理 Agent（src/agent/retrieval/output.py）

> 对应代码：`src/agent/retrieval/output.py`。查询侧子 Agent 之一，**纯 LLM，不查库、不写库**。

## 定位

查询链路的最后一棒：把聚合好的答案整理成用户可读的最终输出。**不接触任何存储**。

## 职责

- **格式化**：解题步骤分步、知识点标注、图表结构化呈现
- **溯源引用**：答案带来源（"2026南昌一模 第15题"），让用户能回查原题
- **分片发送**：长回答按 QQ 消息长度限制分片，避免消息被截断/超限
- **追问引导**：适当追问而非全盘输出，鼓励用户思考（配合系统 Prompt 原则）

## 与 RAG Prompt 的关系

输出整理复用 [README.md 检索增强 Prompt](../README.md) 的约束：

```
1. 解题思路分步骤
2. 标注每步用到的知识点
3. 引用来源（哪份试卷第几题）
```

## 决策原则

- 引用来源是硬要求（检索命中的题目/讲解必须带出处）
- 涉及图形时结合 `vlm_descriptions` 分析
- 检索结果不足时明说"缺少什么信息"，不硬编答案
